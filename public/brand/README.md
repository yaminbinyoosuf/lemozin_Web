# Brand assets

The official Lemozin artwork was extracted from the supplied brand book
(`Lemozin Branding.pdf`) and is used without recolouring, distortion, or
redrawing.

## Files

| File | Use |
| --- | --- |
| `lemozin-lockup-purple.png` | Compact primary lockup (monogram + wordmark, no descriptor) for the site header. |
| `lemozin-lockup-white.png` | Reversed compact lockup for the mobile menu. |
| `lemozin-stacked-purple.png` | Full primary logo, including the “Personal Driving Mentor” descriptor, for the footer. |
| `lemozin-stacked-white.png` | Reversed full logo for dark surfaces and sharing artwork. |
| `lemozin-mark-purple.png` | Monogram only. |
| `lemozin-mark-white.png` | Reversed monogram. |
| `-480`, `-400`, `-800`, `-960` suffixed files | Smaller raster sizes used by `srcset`. |

Favicons (`/favicon-32.png`, `/favicon-192.png`, `/favicon-512.png`,
`/apple-touch-icon.png`) place the official reversed monogram on the brand
purple `#4E008B`. `public/og-image.png` composes the reversed full logo with
the site's hero photograph.

## Rules

- Do not recolour, outline, stretch, rotate, or re-crop the artwork.
- Keep clear space around the logo at least equal to the height of the
  monogram's rounded corner.
- Use the white artwork only on dark purple or photographic backgrounds.
- The header deliberately uses the lockup without the descriptor so the
  wordmark remains legible at small sizes. The full stacked logo is used where
  space allows.
